## Límite honesto de este export

Claude Code en la nube no expone el texto literal de las conversaciones de
otras sesiones. Lo que sí queda registrado, y es lo que se exporta, es:

- los **mensajes de commit**, que en este proyecto describen la petición, la
  decisión y la verificación de cada cambio;
- los **documentos de bitácora** que siguen en el repositorio
  (`docs/CHANGELOG.md`, `docs/DECISIONES.md`, `docs/ARCHITECTURE.md`,
  `docs/TESTING.md`, `docs/OPERATIONS.md`);
- los **metadatos de la sesión** (título, fechas, rama, último estado).

Abre una sesión nueva sobre este repositorio, en la rama
`claude/yugo-user-interface-xeq4er`, y pega como primer mensaje:

```
Este proyecto ya tiene historial con Claude Code desde otra cuenta.
Antes de hacer nada, lee docs/historial-claude/00-INDICE.md y
docs/historial-claude/05-yugo.md: ahí está la ficha del proyecto, su
contexto, las reglas de trabajo y la cronología completa de lo que se
pidió y se hizo. Después lee docs/CHANGELOG.md y docs/DECISIONES.md.
Cuando termines, dime en qué estado quedó el proyecto y qué era lo
siguiente pendiente.
```
